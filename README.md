# fratayaydn/homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask fratayaydn/tap/nightkeys
brew install --cask fratayaydn/tap/balancekeeper
brew install --cask fratayaydn/tap/capsnow
brew install --cask fratayaydn/tap/mickeeper
brew install --cask fratayaydn/tap/fullscreenkeeper
```

| Cask | App |
| --- | --- |
| `nightkeys` | [NightKeys](https://github.com/fratayaydn/nightkeys): keyboard backlight that only wakes for the built-in keyboard |
| `balancekeeper` | [BalanceKeeper](https://github.com/fratayaydn/balancekeeper): puts the left/right audio balance back when macOS shifts it |
| `capsnow` | [CapsNow](https://github.com/fratayaydn/capsnow): turns off the Caps Lock delay |
| `mickeeper` | [MicKeeper](https://github.com/fratayaydn/mickeeper): keeps AirPods and iPhones off the microphone, can lock its level |
| `fullscreenkeeper` | [FullscreenKeeper](https://github.com/fratayaydn/fullscreenkeeper): reopens apps in full screen if you quit them in full screen |

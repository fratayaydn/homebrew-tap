# fratayaydn/homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask fratayaydn/tap/nightkeys
brew install --cask fratayaydn/tap/balancekeeper
brew install --cask fratayaydn/tap/capsnow
brew install --cask fratayaydn/tap/mickeeper
```

| Cask | App |
| --- | --- |
| `nightkeys` | [NightKeys](https://github.com/fratayaydn/nightkeys): only your keys wake the keyboard light |
| `balancekeeper` | [BalanceKeeper](https://github.com/fratayaydn/balancekeeper): keeps the audio balance centered, the lightest way |
| `capsnow` | [CapsNow](https://github.com/fratayaydn/capsnow): Caps Lock without the delay, nothing running |
| `mickeeper` | [MicKeeper](https://github.com/fratayaydn/mickeeper): the right mic, at the right level, and AirPods that never sound like a phone call |
